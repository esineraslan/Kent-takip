# Resmî marka varlıkları

Bu klasöre yalnız İBB Kurumsal İletişim tarafından sağlanan ve manifestte SHA-256 değeri kaydedilmiş dosyalar eklenir. Ekran referanslarından logo kırpılmaz, yeniden çizilmez veya otomatik üretilmez.

Beklenen onaylı dosyalar:

- `ibb-logo-light.svg`
- `ibb-logo-dark.svg`
- `app-icon-source.svg`

Dosyalar teslim edilene kadar uygulama erişilebilir metin/ikon fallback'i kullanır. Bu durum prototipte açık bir kısıttır.
