# Onaylı font varlıkları

Rubik ve Urbanist adları `DESIGN.md` tipografi tokenlarıdır. Lisans kanıtı ve gerçek font dosyaları teslim edilmeden binary font paketlenmez; sistem fallback'i kullanılır.

Onay sonrasında her dosyanın lisans kaynağı, SHA-256 değeri, weight/style eşlemesi `docs/BRAND_ASSET_MANIFEST.json` içine eklenmeli ve `pubspec.yaml` referansları aynı değişiklikte açılmalıdır.
